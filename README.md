# TournamentHub

Учебный MVP для проведения турниров по киберспорту и настольным играм. Стек: Python, Flask, SQLite, HTML, CSS и Jinja2.

## Возможности

- Регистрация, вход, выход, профиль; пароли хранятся в виде хеша.
- Роли `user`, `organizer`, `admin`; назначение роли доступно только администратору.
- Создание команд, приглашение пользователей по email, принятие/отклонение приглашений.
- Создание турниров с игрой, правилами, размером команды, вместимостью 4/8/16, датами и статусом.
- Заявки команд, принятие/отклонение организатором, фиксация состава на момент заявки.
- Сетка single-elimination со случайным посевом, защитой от повторной генерации и переходом победителей.
- Счёт и победитель проверяются на сервере; ничья запрещена, результат после подтверждения неизменяем.
- Публичная сетка, карточки турниров и команд, адаптивный интерфейс.
- Страницы 400/403/404, flash-сообщения, пустые состояния и базовые индексы SQLite.

## Требования

- Python 3.10+
- pip

## Запуск на Windows

Откройте терминал в папке проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
flask --app app init-db
flask --app app seed
python app.py
```

Если PowerShell запрещает активацию виртуального окружения, можно запускать напрямую:

```powershell
py -m pip install -r requirements.txt
py -m flask --app app init-db
py -m flask --app app seed
py app.py
```

Откройте http://127.0.0.1:5000

## Демо-аккаунты

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `Admin123!` |
| Организатор | `organizer` | `Organ123!` |
| Капитан Alpha | `captain1` | `Player123!` |
| Капитан Bravo | `captain2` | `Player123!` |
| Капитан Charlie | `captain3` | `Player123!` |
| Капитан Delta | `captain4` | `Player123!` |

Демо-команды созданы с размером состава 1 для быстрой проверки полного цикла турнира. Для многопользовательского турнира создайте пользователей, команды и приглашения.

## Быстрый сценарий демонстрации

1. Войдите как `organizer`.
2. Откройте демо-турнир **TournamentHub Cup**.
3. Заявки демо-команд отображаются только после их подачи. Войдите капитанами и отправьте заявки; затем организатор принимает их.
4. Когда принято ровно 4 команды, нажмите «Сгенерировать сетку».
5. Откройте полуфинальные матчи, введите счёт и выберите победителя. Победитель появится в следующем раунде.
6. Завершите финал — турнир получит статус «Завершён».

## Важные ограничения MVP

- Сетка поддерживает только полное заполнение всех мест, как требует ТЗ.
- Приглашение доступно пользователю, который уже зарегистрирован по указанному email.
- Для простоты SQLite и серверные HTML-формы используются без отдельного REST API; ошибки доступа и бизнес-правила проверяются сервером.
- Для production необходимо задать уникальный `SECRET_KEY`, выключить debug-режим, использовать HTTPS, добавить CSRF-защиту, rate limiting, миграции (например, Flask-Migrate) и тесты.
- Поля времени вводятся в локальном формате браузера; приложение предполагает, что сервер и пользователь работают в согласованном часовом поясе.

## Запуск через Visual Studio Code

### 1. Подготовка

1. Установите Python 3.10 или новее.
2. Установите Visual Studio Code и расширение **Python** от Microsoft.
3. Распакуйте архив `TournamentHub.zip`.
4. В VS Code выберите **File → Open Folder** и откройте именно папку `TournamentHub`.

### 2. Установка зависимостей (один раз)

Откройте меню **Terminal → New Terminal** в VS Code и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m flask --app app init-db
.\.venv\Scripts\python.exe -m flask --app app seed
```

Если команда `py` не найдена, переустановите Python с сайта python.org и включите опцию **Add Python to PATH**.

### 3. Запуск сайта

**Вариант A — одной кнопкой через отладчик VS Code:**

1. Откройте вкладку **Run and Debug** (значок ▶ с жуком слева).
2. В списке выберите **TournamentHub (Flask)**.
3. Нажмите зелёную кнопку запуска.

**Вариант B — запустить файл:**

Откройте `run.py` и нажмите **Run Python File** в правом верхнем углу редактора.

**Вариант C — через терминал:**

```powershell
.\.venv\Scripts\python.exe run.py
```

Когда в терминале появится адрес сервера, откройте **http://127.0.0.1:5000** в браузере. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале или кнопку Stop в панели отладки.

### Если сайт не запускается

- Если ошибка `No module named flask`, повторите установку зависимостей командой `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.
- Если порт 5000 занят, закройте другое приложение, использующее его, либо измените порт в `run.py` и `.vscode/launch.json`.
- Если нужно начать с чистой базы, остановите сайт и удалите файл `tournamenthub.db`, затем выполните команды `init-db` и `seed` ещё раз. Удаление базы удалит локальные данные.
- После изменения файлов обновите страницу браузера. При запуске через `run.py` включён режим отладки для локальной разработки.
